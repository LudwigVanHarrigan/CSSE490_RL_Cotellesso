# Lab 3: Dynamic Programming

## Overview
This lab explores Dynamic Programming (DP) methods for solving MDPs when the model (transition probabilities and rewards) is fully known. You will implement Policy Evaluation, Policy Iteration, and Value Iteration algorithms.

## Objectives
- Implement the Policy Evaluation algorithm
- Implement Policy Iteration to find an optimal policy
- Implement Value Iteration as an alternative to Policy Iteration
- Compare the convergence speed of Policy Iteration and Value Iteration

## Instructions
1. Use the grid-world MDP from Lab 2
2. Implement Policy Evaluation to compute the value of a given policy
3. Implement Policy Iteration and run it until convergence
4. Implement Value Iteration and compare results to Policy Iteration

## Files

## Deliverables
- Completed `lab3.py`
- Short write-up answering the reflection questions below

## Reflection Questions
1. How many iterations did Policy Iteration require to converge?
2. How does Value Iteration differ from Policy Iteration in terms of computational cost?
3. What are the limitations of Dynamic Programming methods for real-world problems?
