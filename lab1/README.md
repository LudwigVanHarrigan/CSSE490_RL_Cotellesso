# Lab 1: Introduction to Reinforcement Learning

## Overview
This lab introduces the foundational concepts of Reinforcement Learning (RL). You will set up your development environment and explore the basic components of an RL system: agents, environments, states, actions, and rewards.

## Objectives
- Set up the Python environment and required libraries (e.g., NumPy, OpenAI Gym)
- Understand the RL problem formulation
- Implement a simple random agent and observe its behavior in a basic environment

## Instructions
1. Follow the environment setup guide to install dependencies
2. Explore the provided environment and understand its state/action spaces
3. Implement a random agent that selects actions uniformly at random
4. Run experiments and record observations

## Files
- `lab1.py` — Starter code for the lab

## Deliverables
- Completed `lab1.py`
- Short write-up answering the reflection questions below

## Reflection Questions
1. What is the role of the reward signal in RL?
2. How did the random agent perform? What are its limitations?
3. What would a better policy look like for the environment you used?
