# Lab 5: Temporal Difference Learning

## Overview
This lab covers Temporal Difference (TD) learning, which combines ideas from Dynamic Programming and Monte Carlo methods. You will implement the SARSA (on-policy) and Q-Learning (off-policy) algorithms.

## Objectives
- Understand the TD error and how it drives learning
- Implement the SARSA algorithm for on-policy control
- Implement the Q-Learning algorithm for off-policy control
- Compare SARSA and Q-Learning on a classic control problem

## Instructions
1. Implement TD(0) prediction to estimate the value function
2. Implement SARSA for on-policy control
3. Implement Q-Learning for off-policy control
4. Evaluate and compare both algorithms on a given environment

## Files
- `lab5.py` — Starter code for the lab

## Deliverables
- Completed `lab5.py`
- Short write-up answering the reflection questions below

## Reflection Questions
1. What is the TD error and what does it represent?
2. How do SARSA and Q-Learning differ in their update rules?
3. In what situations might SARSA be preferred over Q-Learning, or vice versa?
