# Lab 2: Markov Decision Processes (MDPs)

## Overview
This lab covers Markov Decision Processes, the mathematical framework underlying most RL algorithms. You will formalize RL problems as MDPs and work with transition models and reward functions.

## Objectives
- Understand the components of an MDP: states, actions, transition probabilities, rewards, and discount factor
- Implement a simple grid-world MDP from scratch
- Compute expected returns under a given policy

## Instructions
1. Implement the grid-world MDP environment
2. Define a policy and compute the value function for that policy
3. Experiment with different discount factors and observe their effect on the value function

## Files
- `lab2.py` — Starter code for the lab

## Deliverables
- Completed `lab2.py`
- Short write-up answering the reflection questions below

## Reflection Questions
1. What is the Markov property and why is it important?
2. How does the discount factor influence the agent's behavior?
3. What happens to the value function as the discount factor approaches 1?
